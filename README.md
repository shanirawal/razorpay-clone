# Razorpay Clone - Learning Tailwind CSS & Responsive Design

## 🚀 Project Preview: https://razorpay-clone-shanirawal.netlify.app/

## 🚀 Project Overview

This project is a responsive clone of the Razorpay payment gateway website, built primarily to learn and practice Tailwind CSS with a focus on responsive design principles. By recreating Razorpay's modern, clean UI, I've gained hands-on experience with Tailwind's utility-first approach while ensuring the site looks great on all device sizes.

## 🎯 Learning Objectives

- Master Tailwind CSS fundamentals and utility classes
- Implement responsive design using Tailwind's breakpoint system
- Create modern UI components without writing custom CSS
- Understand mobile-first design principles
- Practice layout techniques using Flexbox and Grid through Tailwind

## 🛠️ Technologies Used

- **HTML5** - Semantic markup structure
- **Tailwind CSS** - Utility-first CSS framework
- **JavaScript** - For interactive elements
- **Vite** - Frontend build tool for fast development

## 🔍 Features

- **Responsive Hero Section** - Eye-catching header that adapts across all devices
- **Feature Showcase** - Grid-based layout highlighting key features
- **Pricing Cards** - Responsive pricing tables that reflow on smaller screens
- **Testimonials Section** - Customer reviews in a mobile-friendly carousel
- **Navigation Menu** - Responsive navbar with mobile hamburger menu
- **Footer** - Comprehensive footer with responsive column layout

## 💡 Tailwind CSS Concepts Implemented

- **Container & Spacing** - Using container and spacing utilities for layout
- **Flexbox & Grid** - Building complex layouts with Tailwind's flex and grid utilities
- **Colors & Typography** - Implementing a consistent color scheme and type system
- **Responsive Breakpoints** - Using `sm:`, `md:`, `lg:`, `xl:` prefixes for responsive design
- **Custom Configuration** - Extending Tailwind's default configuration
- **Dark Mode** - Implementing dark mode using Tailwind's dark mode utilities
- **Transitions & Animations** - Adding smooth interactions with Tailwind

## 📱 Responsive Design Approach

This project follows a mobile-first approach, where the base styles are designed for mobile devices and then progressively enhanced for larger screens:

- **Mobile (< 640px)**: Single column layouts, optimized for touch
- **Tablet (640px - 1024px)**: Two-column layouts where appropriate
- **Desktop (> 1024px)**: Multi-column layouts with more complex arrangements

## 🚀 Getting Started

### Prerequisites

- Node.js (v14.0.0 or above)
- npm or yarn

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/shanirawal/razorpay-clone
   cd razorpay-clone
   ```

2. Install dependencies:
   ```bash
   npm install
   # or
   yarn install
   ```

3. Start the development server:
   ```bash
   npm run start
   # or
   yarn start
   ```

4. Open your browser and visit `http://localhost:3000`
